# RynnUnify project website

Static project website for **RynnUnify: Towards Unified Embodied Brain**.

Website: https://hbhalpha.github.io/RynnUnify-IJCV/

## Editing

`index.html` contains the page and manuscript results. `data.js` contains the
curated demonstration metadata. Styles and interactions are plain CSS and
JavaScript; there is no build step or runtime dependency.

Serve this directory with a local static server to preview changes.
GitHub Pages publishes the root directory of the `main` branch.

Paper, model, and research-code links are configured in `links.js` when available.
Only the media used by this version of the page are included.
